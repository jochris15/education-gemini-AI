# Implementation Gemini AI to our project

## SETUP
Untuk implementasi `GEMINI AI` pada project kita, kita bisa menggunakan `Google AI Studio`.
Step by step setup adalah sebagai berikut:
1. Buatlah `API KEY` pada [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key)
2. Ikuti langkah-langkah pada dokumentasi resmi [Google AI Studio](https://ai.google.dev/gemini-api/docs/get-started)

## DEMO 
Pada demo kali ini, kita akan implementasikan `GEMINI AI` untuk mendapatakan data pokemon paling populer hari ini. Kita akan implementasikan AInya di **server** supaya kita bisa mendapatkan data pokemon lengkapnya dari `POKE API`
